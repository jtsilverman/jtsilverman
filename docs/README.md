# docs/

The four kinds of doc a session reads before touching this repo: architecture, conventions,
runbooks, decisions.

This repo holds one file. `README.md` renders as Jake's GitHub profile page. The docs exist because
the rules governing that file live outside it, in another repo, and a session that edits the profile
without reading them will violate one.

| File | Question it answers |
|---|---|
| `architecture/what-this-repo-is.md` | What the one file is, how GitHub renders it, what the sections are |
| `conventions/profile-readme.md` | Posture, bullet shape, repo naming, how a private repo is written |
| `runbooks/edit-and-verify.md` | Edit, push, confirm the render, rename a linked repo |
| `decisions/never-rename-this-repo.md` | Why the repo name is load-bearing |

The governing rules live at `~/Documents/projects/Employment/.claude/rules/employment.md`, section
"GitHub profile-README posture". These docs point at that file rather than restating it, and record
the two places the current README departs from it.
